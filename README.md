Situação-Problema:
A situação-problema escolhida é a necessidade de uma interface simples e funcional para uma loja de lanches delivery apresentar seu cardápio de forma clara, objetiva e acessível, permitindo ao cliente visualizar os produtos e realizar o pedido rapidamente pelo WhatsApp.
A solução proposta é um MVP que demonstra a navegação básica de um sistema de cardápio digital.

Descrição do MVP:

O MVP consiste em uma interface front-end composta por 3 telas principais, seguindo os requisitos funcionais e não funcionais definidos:
Tela Home – Introdução da loja e chamada para ação.
Tela de Cardápio – Apresentação dos produtos com imagens, descrição e preços.
Tela de Pedido – Botão que leva o cliente diretamente para o WhatsApp com mensagem automática preenchida.
O objetivo é validar a ideia inicial de um cardápio digital simples, responsivo e intuitivo.

Requisitos Atendidos:

Requisitos Funcionais;
Exibir lista de produtos disponíveis;
Mostrar imagem, descrição e preço de cada item;
Possibilitar a ação “Fazer Pedido”;
Redirecionar para o WhatsApp com mensagem pré-definida;
Navegação entre as 3 telas principais.

Requisitos Não Funcionais:

Layout responsivo;
Código organizado e de fácil manutenção;
Interface clara, simples e intuitiva;
Carregamento rápido;
Boa usabilidade no mobile.
