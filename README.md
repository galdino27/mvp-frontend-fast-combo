# Fast Combo RJ — MVP Front-End

**Equipe:** Trabalho individual - Ibson Bernardino
**Disciplina:** MVP Front-End Development
**Data de entrega:** 2025-12-06

## Situação-problema
Desenvolver um MVP Front-End para uma loja de delivery local (Fast Combo RJ) que permita visualizar o cardápio, adicionar itens ao carrinho e simular um checkout. O objetivo é demonstrar conhecimentos de prototipação, desenvolvimento HTML/CSS/JS e documentação.

## Descrição do MVP
Aplicação web responsiva, composta por:
- Tela inicial (hero) com botão para ver o cardápio.
- Tela de cardápio com lista de produtos e botão "Adicionar".
- Tela de carrinho com resumo de itens e total.

## Como executar localmente
1. Baixe os arquivos.
2. Abra o arquivo `index.html` em um navegador moderno (Chrome, Firefox, Edge).
3. Não é necessário servidor — é um MVP estático usando HTML/CSS/JS.

## Instruções para versionamento no GitHub
1. Crie um repositório em sua conta.
2. Faça os commits com as alterações e envie para `main`.
